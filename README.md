
Made in Visual Studio. 
Code requires the Vulkan SDK to compile. 

Check the Demo folder to see an example of this running. 
https://github.com/AndrBy1/A-Vulkan-Engine is the version made in VS Code and is set to work across OS platforms

External tools used: 
GLFW for window creation: https://www.glfw.org/
GLM for math functions: https://www.opengl.org/sdk/libs/GLM/
Tiny Object Loader: https://github.com/tinyobjloader/tinyobjloader
Stb Image: https://github.com/nothings/stb

Borrowed code: 
VulkanBuffer by Sascha Willems: https://github.com/SaschaWillems/Vulkan/blob/master/base/VulkanBuffer.h
